`campus.json` is a derivative database of OpenStreetMap geometry, retrieved 2026-10-18, simplified and transformed into a local meter coordinate system. It contains building outlines, campus/dormitory boundaries, roads, sports areas and water features. Origin: longitude 112.940, latitude 28.175, WGS84; X east, Z south.

The generated architecture and interior templates are separate illustrative application elements. The OSM database does not contain the estimated floor heights, facade decoration or room arrangements used by the application.
