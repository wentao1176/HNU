# 湖南大学三维校园设计

目标是交付可直接部署到 GitHub Pages 的纯前端三维校园。用户能在 PC 和手机浏览器浏览湖南大学南校区、天马与德智公寓、财院校区，搜索地标，切换鸟瞰与第一人称，进入楼宇查看示意室内。望麓桥公寓收录公开可获取的园区边界。

地理依据为湖南大学官方南校区功能分区图、学校新闻的建筑介绍、OpenStreetMap 楼宇轮廓与道路。场景中保留真实地理相对位置与楼体平面轮廓，重点建筑通过独立立面语言塑造。非公开的楼层平面、房间与尺寸按示意处理并显著标明。产品不使用学校照片或地图瓦片作为运行时依赖。

主界面是满屏 WebGL 视图，叠加克制的搜索、地标目录、建筑详情、模式控制和移动端摇杆。初始展示校园总览。点击/搜索建筑后镜头平滑聚焦，详情提供进入建筑按钮。步行模式使用键盘鼠标或手机触控；室内有可离开的出口。场景含道路、地面、水体、运动场、树、建筑屋顶与多层立面。

技术采用 Vite + Three.js + 原生 JavaScript/CSS，所有模型程序生成，几何数据静态打包。不依赖 API 密钥和服务器。默认按设备降低像素比与阴影开销，可手动选择画质。来源与示意边界写入界面和 README，OpenStreetMap 数据保留署名与 ODbL 链接。

用户后续强调地图准确、范围不限于举例建筑、尽可能高清。因此扩展数据边界并加入财院校区，提供 103 个可搜索地点、最高 3 倍渲染和最长边 3840 像素的 PNG 导出。最终数据包含 430 个公开楼体轮廓，单栋或室内资料不足处保留示意标记。
