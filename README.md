# 岳麓书院 · 三维复原

纯前端三维复原，零外部素材：砖瓦木石纹理、树木、屋顶、匾额楹联、室内陈设、牌位碑刻，全部由代码实时生成。
总平面以 **OpenStreetMap 实测建筑轮廓**为锚（赫曦台、教学斋、半学斋、御书楼、大成殿、崇圣祠、文昌阁、明伦堂、专祠对角带、吹香亭、风雩亭、自卑亭等均按实测坐标与尺寸落位），结合文献考证复原：

- 中轴序列：**头门 → 赫曦台 → 大门 → 二门 → 讲堂 → 御书楼**（赫曦台居大门前坪，行人由两翼过道绕行）
- 文庙位于书院**北侧**，自成东西轴线、整组朝东（照壁 → 大成门 → 两庑 → 大成殿 → 崇圣祠，明伦堂居北朝南）
- 专祠群沿实测**对角带**布置、祠宇面朝东北：慎斋祠 → 船山祠 → 六君子堂 → 崇道祠 → 四箴亭 → 濂溪祠
- 吹香亭在头门北侧池中（「风荷晚香」），风雩亭在南侧土丘

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产出 dist/，可直接静态部署
```

## 能走进去的路线

**自卑亭 → 东门 → 头门 → 赫曦台（两翼过道）→ 大门 → 二门 → 讲堂（入室）→ 教学斋 / 半学斋 → 湘水校经堂 → 御书楼（入室）→ 拟兰亭 / 汲泉亭 → 百泉轩 → 麓山寺碑亭 → 文庙仪门 → 大成门 → 大成殿（入殿）→ 明伦堂 → 文昌阁 → 西门 → 爱晚亭**

点右上角 **「导览」** 即按此路线逐站飞行，共 18 站，每站配讲解；可用「上一站 / 下一站」翻页。
也可以切到**步行**模式，自己从头门一路走到西门——门洞是通的，台基会抬脚，墙会挡人。

## 准确度与限制

- 平面位置来自公开地图实测；**楼高、立面细节、室内陈设、植被、地形起伏为按形制与史料推定的复原**，非测绘成果。
- 室内家具为示意性复原，尺寸与真实器物有出入；讲堂的朱张会讲场景未做人物。
- 斗拱、格心、脊饰为写意简化。
- 天空在正午偏白（Sky 辐亮度与 ACES 的平衡仍未调好）。
- 程序化纹理在 1 米内仍可见重复。

## 精细度（第三轮打磨）

| 部位 | 做法 |
|---|---|
| 屋面 | 高精度档用**真实几何瓦垄**（0.36m 间距筒瓦，逐段沿举折曲面放样，带侧壁），不再只靠贴图；环数 22、每边 20 段 |
| 正脊 | 分五层：脊座 → 脊筒 → 上枭混 → 瓦条 → 两端脊头，另有鸱吻 |
| 戗脊 | 每条戗脊布 5 只走兽，由檐向脊渐小 |
| 柱 | 梭柱做法（中段略鼓、上下收分），28 边 |
| 柱础 | 圭角 / 下枋 / 束腰 / 上枋 / 覆盆 五段须弥座 |
| 台基 | 高精度档改须弥座分层（圭角、下枋、下枭、束腰、上枭、上枋） |
| 隔扇 | 格心加卡子花（十字小件），棂条 0.026m |
| 材质 | 砖墙加雨痕与底部潮痕；白灰墙加霉斑与剥落；朱漆柱加漆面裂纹；瓦面加釉光（roughness 0.86） |
| 光照 | 三光源（主光 + 补光 + 反方向轮廓光），阴影 radius 1.1、normalBias 0.012 |

高精度档目前给大门、讲堂、大成殿三处；其余用标准档（贴图瓦垄）以保证加载速度。

**性能提示**：首次加载要 60–120 秒生成几何与贴图（纯 CPU），之后渲染正常。这是纯前端程序化建模的固有代价。

## 第五轮：空间关系与光影重做

这一轮不堆构件，专修"看起来不对"的地方。

### 天空换掉了

原来的 `three/addons` Sky 走 Preetham 模型，在 ACES 色调映射下整片天被压成灰白，怎么调参数都不对。改成**自写穹顶着色器**：

- 天顶 → 地平线渐变（`pow(1-h, 2.6)`），地平线附近叠大气霾
- 太阳圆盘 + 三层光晕（`pow(dot, 420/18/3)`）
- 程序化云：把视线方向投影到高空平面，5 阶 fbm 造絮状，云底灰、云顶亮、向阳面有银边，随 `uTime` 缓慢漂移

### 山体从"绿坡"变成"林山"

- 原来 760 棵树撒在 98 万 m² 上，等于没有。现在分四层布：院墙外近坡（完整模型 380 株）、山坡（低模 1300）、远山（低模 2000）、南北翼（各 600）
- 远景树用**低模叶簇**（9 簇、簇径放大 4.4 倍）且**不投影**——远看是树冠团块，近看也不穿帮
- 地形加**坡度露岩**：按邻域高差算坡度，陡坡混入岩石色
- 雾浓度 0.00046 → 0.00115，远山有了空气透视，不再是黑墙

### 铺地改成路网

原来中轴铺一条 22 米宽的大石板，像广场。现在是**御道 6.4 米 + 各院支路 2.4–3.2 米**，按真实动线排：东门外 → 大门 → 赫曦台 → 二门 → 讲堂 → 两厢 → 御书楼 → 西门，另有文庙轴线、百泉轩小径、角门小路。

### 入口序列修好了

之前东墙横在 u=-30，把大门（u=-14）关在墙里面——人根本进不去，而且照壁正对轴线挡住整座门。现在：

- 大门移到 u=-30，**坐在东墙上**，墙体在该处开口 23 米
- 牌坊 u=-56、东门 u=-70 依次外推，形成"牌坊 → 前庭 → 大门"的序列
- 照壁从轴线上撤掉（挡视线），第三站改为「前庭」
- 大门、二门改 `backType: 'open'`，前后贯通，能看见院内

### 匾额位置修正

原来匾额贴在门额平面上，从前廊看等于挂在门洞里。现在**有前廊的建筑，匾挂到檐下廊外沿**，并补了挂枋和吊杆——这才是「实事求是」匾在真实照片里的位置。

### 几处材质

- 青瓦 104 → 82 灰阶、环境反射 0.34 → 0.28（原来像铝板）
- 白灰墙 0xded7c6 → 0xbfb8a4，花岗岩 0xc8c4ba → 0x94908a
- 窗纸加自发光，隔着棂条能看出纸的透光
- 朱漆柱 0x8a5a48 → 0x6b4034（岳麓书院的柱子接近黑褐）
- 太阳强度 4.1 → 3.5，解决檐口过曝成白边

### 布局错误

吹香池原先放在 (2, 86)，正好压在文庙院子里（明伦堂 v=79.8）。移到院墙外 (186, -30)，吹香亭立到池心；删掉挡在御书楼轴线上的「月池」。

### 调试工具

`scripts/shot.mjs` 支持 `CAMS='[[cu,cv,cy,lu,lv,ly],...]'` 一次加载拍多个机位（`window.__setCamUV`），省去反复重载。构建耗时统计挂在 `window.__timings`。

## 第六轮：总平面按实测重建（2026-10）

以 Overpass API 重新抓取书院范围全部 OSM 建筑轮廓（含节点级几何），换算到本地 u/v 坐标系逐座核对，并据官网形制描述与诸家史料重排总平面。本轮修正：

**序列性错误（最关键）**
- 原布局「大门(u=-30) → 赫曦台(u=0)」与实况相反。据「罗典乾隆五十五年建赫曦台于大门前坪」「跨进头门两三米赫曦台迎面而立」等记载及实测，改为 **头门(-13.5) → 赫曦台(0) → 大门(20) → 二门(33)**，赫曦台两翼设过道，行人绕行而入。
- 新增**头门**（原缺），悬「千年学府」匾。

**位置与朝向**
- 吹香亭由 (186,-30)（原误放西南远郊）按实测移回**头门北侧池中 (-7.8, 91.5)**，吹香池随之；文泉、曲涧移至百泉轩一带（南侧）。
- 大成殿 (100,58) → (85,60.8)，与月台实测轮廓吻合；文庙照壁、大成门按轴线（v=60.8）重排。
